Vier Sätze.
Das ganze Rennen.

  1. 6,706 km

    Die Runde, der „Yard". Jede Stunde dieselbe Schleife. 24 davon ergeben genau 100 Meilen.

  2. Zur vollen Stunde

    Jeder Yard startet gemeinsam, immer zur vollen Stunde. Wer den Start verpasst, ist raus.

  3. Keine Hilfe

    Auf der Strecke zählst nur du und die Uhr. Keine Begleitung, keine Stöcke.

  4. Einer bleibt

    Das Rennen endet erst, wenn nur eine Person eine weitere Runde antritt. Sie gewinnt, alle anderen bekommen ein DNF.
